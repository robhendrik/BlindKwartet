## 1. Kwartet Without Cards Always Ends in Confusion
Train to a physics conference, ~1994–95; a friend brings kwartet with the Dutch rules but blind. What is on the cards is made up as we go, as long as the story stays consistent. Friends argue whether an answer was allowed. Later played with the kids. One seed line: I wondered whether there was a strategy.
*Bridge:* we need a way to settle whether a question or answer is still allowed.

## 2. Keeping Track Means Keeping Every Possible World
Rules in a few lines. A world is a complete deal consistent with everything said; the multiverse is the set of worlds still possible; an illegal move leaves it empty. For three players and three categories of four: 34,032 worlds (12!/(4!)³ = 34,650, minus 618 with an initial quartet), so one bit per world.

> **Pull quote 1 (Reveal 1):** At the start every card is interchangeable. Yet keeping track of the game takes a 34,032-bit number.

*Bridge:* if everything is interchangeable, why can't we use that?

## 3. Interchangeable Cards, and Nothing to Exploit
Label every card A1 to C4 in advance and any world can occur, so the bookkeeping never sees the symmetry. Optional figure, only if it earns its place: how much of the starting multiverse is relabelling (34,032 → 87 count tables → 16 → 6 shapes).
*Bridge:* can we start with truly blank cards and attach names as we go?

## 4. Let the Cards Start Blank
Fix the physical cards in the hands; names are the unknowns. "Flowers" and "rose" appear the first time someone says them. Every question and answer restricts which name can belong to which card. The names that exist at the end are the ones the players created.
*Bridge:* the question becomes whether the names still open fit the blank cards.

## 5. Can Every Blank Card Still Get a Name?
The known problem: applicants and jobs (the Pythagoras example). Each job suits some applicants; can everyone get one? Hall's condition (any k jobs together need at least k applicants), 1935. Name and date come after the reader has seen the problem.

> **Pull quote 2 (Reveal 2):** Whether a game with no cards is still possible is the question whether everyone can still get a job. *(provisional until the closure question is settled)*

*Bridge:* so there are two descriptions of the same situation.

## 6. Two Ways to Describe the Same Possibilities
The list of worlds against the matching constraints. Matchings modulo hand order give back the 34,650 deals; the rule that no one starts with a complete quartet cuts this to 34,032 and is not an edge constraint. There is no hidden true deal: the answerer chooses, so the multiverse shrinks by choice, not discovery. How far the matching can replace the list is the honest open end here.
*Bridge:* the same check that settles arguments does something more.

## 7. We Can Spot an Illegal Move. Which Move Is Best?
The legality check settles the friends' arguments. It also shows which questions are pointless (asking someone who surely lacks the card), a first taste of strategy. The strategy question from the train remains: next post.
